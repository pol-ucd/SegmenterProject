Ther is a folder named 'annotated_defaultAnnotation' in which there are 210 images of initial frames with polygon overlay available.
Out of three possible anotation versions per video (ann_0,  ann_1,  ann_1_ARCTUR), only one is available - the one that Patrick and I estimated as the most optimal for that case.

There are 4 folders contaning masks, one for each label (healthy, benign, cancerous, other).
Each folder contains binary segmentation masks of corresponding type of segmented objects.

Lesion/polyp is represented by label benign (87 masks) or cancerous (123 masks).

Each mask is named as: [video name]_[label]_mask_[annotation version].png

Example: "01_other_mask_ann_1_ARCTUR.png"
01      	- video name
other       	- label
ann_1_ARCTUR    - annotation version
